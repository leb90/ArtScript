# create-artscript

```sh
npm create artscript@latest my-app
cd my-app && npm install && npm run dev
```

Creates an [ArtScript](https://github.com/leb90/ArtScript) project: `src/app.art`, the spec for your AI agent, and the `dev`, `build` and `check` scripts. Add `-- --template todo` (or `blog`, `users`, `notes`, `catalog`, `crm`) to start from a working app. Needs Node 24 or newer.
